# rowkit.dev 2.0 — бриф на сайт

8 октября 2026 · бриф для дизайнера. Файл: [rowkit × Windows 98](https://www.figma.com/design/hmDfFpjrDP6WtEary6U6SE/rowkit-%C3%97-Windows-98), новая страница «Site v2». Бренд — страница «Brand» (гайд 173:35331).

## Зачем

Сейчас rowkit.dev — эмуляция операционной системы: рабочий стол, Dock, «Пуск», каждая страница в окне Explorer или Finder. Это мило один раз и мешает каждый следующий:

- главная не говорит, что это и почему это стоит взять — она играет в ОС;
- меню слева набрано мелко (13px), текст зажат рамками окна, на телефоне окна тесные;
- переключатель тем — мелкий текст в панели задач, его не находят.

Нужен **сайт продукта**: красивый лендинг и удобная документация. Две темы остаются главным аргументом, но как витрина, а не как костюм: один и тот же сайт выглядит как Windows 98 или как modern, и это видно с первого экрана.

## Аудитория и что она должна понять

Фронтенд-разработчик или тимлид, который выбирает набор компонентов для продуктового интерфейса на Vue 3 (админка, внутренний инструмент, SaaS). За 10 секунд на главной он должен понять:

1. **Что это:** профессиональный набор компонентов для продуктовых интерфейсов на Vue 3 и TypeScript.
2. **Чем отличается:** один набор — любой вид. Тема — это только токены; Windows 98 и modern в комплекте, свою можно сделать одним вызовом.
3. **Что он серьёзный:** типы, доступность с тестами, своё поведение без сторонних библиотек, SSR, лимит размера, инструкции для ИИ-агентов в пакете.
4. **Что он растёт:** 21 компонент сегодня, план на остальное — меню, даты, палитра команд и т. д.
5. **Как начать:** `npm i rowkit@beta`, две строки CSS.

Тон: точный, спокойный, уверенный, с лёгкой игрой — игра в переключении тем, а не в декорациях.

## Решения, которые уже приняты

- **Весь сайт** — лендинг и документация — в обычном каркасе: шапка, меню слева, текст по центру, оглавление справа. Рабочий стол, Dock, «Пуск», панель задач, окна вокруг страниц уходят.
- **Windows 98 — «шкурка» того же каркаса**, а не другая раскладка: серая грань, фаски, PT Sans, синие выделения, пиксельные иконки. Читается как сайт, узнаётся как Windows 98.
- **Сайт открывается в modern**, Windows 98 — переключателем или `?theme=win98`. Выбор запоминается.
- **Бренд над темами:** знак, вордмарк, vermilion в шапке и подвале одинаковы в обеих темах (в Win98 — пиксельное прочтение знака 16/32).

## Шрифты и размеры (обе темы)

Читать должно быть удобно в первую очередь. Ориентир — modern; Win98 повторяет размеры в PT Sans.

| ------------------------ | --------------- | ----------------------------------------- |
| Заголовок лендинга       | 48–56 / 1.1     | на телефоне 34–36                         |
| Подзаголовок лендинга    | 20 / 30         |                                           |

| H2                       | 24 / 32         |                                           |
| H3                       | 18 / 26         |                                           |

## Каркас документации

**Шапка (64px; телефон 56px).** Логотип · Docs · Components · Patterns · Storybook · GitHub · поиск (⌘K) · **переключатель тем** · версия. Переключатель крупный и подписанный: сегменты «Windows 98 | Modern» и кнопка схемы Auto/Light/Dark. В Win98 — как переключатель на панели инструментов (вдавленная кнопка у выбранной), в modern — сегментированный контрол.

**Меню слева (260px).** Разделы: Guide, Components (Foundations / Forms / Data / Overlays), Patterns, Foundations · Tokens, Decisions, Roadmap, Contributing. Все разделы раскрыты; текущая страница подсвечена; меню прокручивается отдельно от страницы. На телефоне — выезжающая панель из кнопки в шапке.

**Содержимое (до 720px).** Хлебные крошки → H1 → вводный абзац (крупнее, 18/28) → разделы. Примеры: живой пример над кодом, код со строкой «Copy». Таблицы props — как сейчас (генерируются), но в ширину колонки без горизонтального скролла. Внизу: «Previous / Next», «Edit on GitHub», дата.

**Справа (220px, ≥1280px).** «On this page» с подсветкой текущего раздела.

**Поиск.** Одна палитра поиска по ⌘K в обеих темах (сейчас Spotlight в modern, окно Find в Win98): поле, недавние, результаты по группам, «ничего не найдено». В Win98 — диалог с фаской, в modern — карточка со стеклом.

**404.** Обычная страница в каркасе: «Page not found», адрес, «Go to Home», поиск.

## Лендинг

Ширина контента 1200px, секции с воздухом (96–128px между ними, на телефоне 64). Сверху вниз:

1. **Первый экран.** Слева: заголовок «Vue 3 components for product interfaces», подзаголовок («A professional toolkit — typed, accessible, themeable. Windows 98 and modern in the box, your own in one call.»), команда установки с кнопкой копирования, кнопки «Get started» и «Browse components». Справа: **живое демо** — таблица пользователей с фильтром, выбором и пагинацией в текущей теме (тот же код, что сейчас в «Live demo»). Над демо или под ним — крупный переключатель «Windows 98 | Modern»: клик перекрашивает весь сайт, и это первое, что хочется нажать.
2. **«One set, any look».** Одна и та же форма «New user» дважды рядом — в Windows 98 и в modern (`data-theme` на контейнере, вживую). Ниже — пример `defineTheme` из `rowkit/theme` и третья, «своя» тема рядом (например, фиолетовая): видно, что тема — это значения, а не компоненты.
3. **Что внутри.** Сетка компонентов по разделам (Foundations, Forms, Data, Overlays): у каждого — маленькое живое превью в текущей теме, имя, одна строка «для чего». Отдельной строкой — «Coming next»: меню, Popover, Sheet, даты, палитра команд, Tabs, Switch, Combobox — серыми карточками с пометкой «Planned», ссылка на Roadmap. Это и есть «их будет много».
4. **Почему это профессиональные компоненты.** 6 карточек:
   - **Typed** — дженерики в `DataTable` и `Select`, строгий TypeScript, без `any`;
   - **Accessible** — WAI-ARIA, клавиатура, a11y-проверка в CI на каждой истории;
   - **Own behaviour layer** — фокус, слои, позиционирование без сторонних библиотек;
   - **Tokens all the way down** — `@rowkit/tokens`, 313 токенов с описаниями;
   - **SSR и Nuxt** — работает без настройки;
   - **Ready for coding agents** — `AGENTS.md` в пакете.
     Плюс строка цифр: тесты (~1500), размер (39 kB вся библиотека, 2.6 kB одна кнопка), 21 компонент.
5. **Пример кода.** «A data table page in 20 lines»: код слева, результат справа (FilterBar + DataTable + Pagination).
6. **Начать.** Три шага: установить, подключить стили, выбрать тему — и кнопка «Read the guide».
7. **Подвал.** Логотип, слоган, ссылки (Docs, Components, Roadmap, GitHub, npm, Storybook), MIT, «Built with rowkit».

## Два стиля сайта

| Часть              | Windows 98                                                          | Modern (light / dark)                                     |
| ------------------ | ------------------------------------------------------------------- | --------------------------------------------------------- |
| Фон страницы       | серый `#C0C0C0` для рамок; белый под текстом                        | `background` темы; секции лендинга — едва заметные полосы |
| Шапка              | панель инструментов с фаской снизу, кнопки-иконки                   | полупрозрачная, размытие, линия снизу                     |
| Меню слева         | белая колодезная панель (sunken), синее выделение, пиксельные папки | без рамки, скруглённое серое выделение, контурные иконки  |
| Карточки           | GroupBox с подписью на рамке или raised-панель                      | скруглённые карточки с тенью                              |
| Кнопки, поля       | компоненты rowkit в теме — без своих стилей сайта                   | так же                                                    |
| Заголовок лендинга | PT Sans Bold, чёрный; акцент — синий `#000080`                      | системный шрифт, semibold; акцент — синий темы            |
| Ссылки             | синие, подчёркнутые                                                 | синие, подчёркивание при наведении                        |

Вся «шкурка» — токены темы. Свои цвета сайта — только бренд (знак, vermilion) и подсветка кода `site/code-*`.

## Готово, когда

- главная за 10 секунд отвечает на пять вопросов из «Аудитории»;
- основной текст ≥ 16px, меню ≥ 15px, нигде нет горизонтального скролла на 390–1440;
- переключатель тем виден на любой странице без поиска глазами;
- обе темы и обе схемы проходят контраст AA; Lighthouse Accessibility ≥ 95;
- Windows 98 узнаётся с первого взгляда, но страница читается как обычный сайт.
