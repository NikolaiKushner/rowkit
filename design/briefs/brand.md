# rowkit — мини-бриф на новый бренд

7 октября 2026 · мини-бриф для дизайнера. Нынешние файлы бренда — в [`docs/public`](../../docs/public); бриф на модерн-тему — [`modern-theme.md`](./modern-theme.md).

## Зачем

Нужен бренд, который стоит над темами. Сейчас знак rowkit — пиксельное окно Windows 98 с тёмно-синим заголовком, а логотип набран пиксельным шрифтом. Так библиотека читается как «та самая, в стиле Windows 98». Теперь у rowkit две темы, свои темы может делать кто угодно, а по плану темой по умолчанию станет модерн. Поэтому бренд не должен быть ни Windows 98, ни macOS.

Что должно получиться:

- **Нейтральный к темам бренд.** Знак, логотип и цвет смотрятся уместно и рядом с Windows 98, и рядом с модерн-темой, и на GitHub, и в npm.
- **Бренд профессионального инструмента.** rowkit — типизированная библиотека для продуктовых интерфейсов: таблицы, фильтры, формы. Характер — точный, спокойный, уверенный, с лёгкой игрой (темы — это и есть игра), но без ретро.
- **Идея «один набор — любой вид» видна в бренде.** В превью и README темы показываются как демонстрация, а не как лицо бренда.

Имя rowkit сохраняется. Перерисовать нужно всё из страниц Figma «Brand — rowkit», «Brand files» и «README previews». Пиксельный знак не выбрасывается: он остаётся иконкой приложения внутри Win98-темы сайта, но перестаёт быть логотипом.

## Направление

Бренд строится на идее rowkit: один набор компонентов, любой вид. Сам бренд сдержанный, почти монохромный (чернила и бумага плюс один акцент), а яркость дают темы, которые бренд показывает. Характер: точный, инженерный, спокойный, с намёком на игру. Ориентиры по уровню — бренды Linear, Vercel, Radix: простой знак, сильная типографика, много воздуха. Копировать их не нужно.

Прошу показать 2–3 маршрута знака до того, как делать полный набор. Идеи, с которых можно начать:

| Маршрут                | Идея                                                                                               | Чем силён                                      | Риск                                          |
| ---------------------- | -------------------------------------------------------------------------------------------------- | ---------------------------------------------- | --------------------------------------------- |
| А. Ряды                | Три горизонтальные полосы разной длины, средняя «выделена» акцентом — строки таблицы, одна выбрана | Сразу говорит row и «данные»; читается в 16px  | Близко к иконке «меню» или «список»           |
| Б. Два угла            | Квадрат с двумя разными углами: один острый, один скруглённый — один компонент, две темы           | Идея тем в одной форме; очень простой          | Может выглядеть случайной фигурой без подписи |
| В. Монограмма из сетки | Строчная r (или rk), собранная из ячеек сетки — строки и колонки                                   | Узнаваемая буква, модульность как у библиотеки | Сетка напомнит пиксели и тащит назад в ретро  |

Интересный ход для любого маршрута: знак сам «темизируется». Основная версия нейтральная, а внутри каждой темы сайта есть своё прочтение того же силуэта: пиксельное с фаской в Windows 98, скруглённое со стеклом в модерн-теме. Так знак сам демонстрирует продукт.

**Логотип:** «rowkit» строчными буквами, спокойный гротеск с доработкой (кернинг, свой рисунок k или t). Без пиксельных и моноширинных шрифтов.

**Ключевой визуал для превью и README:** один и тот же экран (таблица пользователей), разрезанный по диагонали или веером на темы: Windows 98, модерн светлая, модерн тёмная, пример своей темы. Фон и рамка вокруг — в цветах бренда, не темы.

## Требования

- **Знак работает в 16px.** На фавиконке и в заголовке окна он должен читаться. Для 16 и 32px нужны отдельные отрисовки, подогнанные по пиксельной сетке.
- **Один цвет без потери смысла.** Знак и логотип есть в цветной, чёрной и белой версиях. На светлом и тёмном фоне GitHub выглядят одинаково хорошо.
- **Цвет бренда не совпадает с акцентами тем.** Не тёмно-синий `#000080` из Windows 98 и не синий `#0071E3` из модерн-темы, иначе бренд снова привяжется к одной из них. Выбор за вами. Нужна пара чернила / бумага и один акцент, который проходит 4.5:1 с белым текстом или на белом фоне.
- **Шрифт с открытой лицензией (OFL).** На нём строятся превью и баннеры. Если логотип нарисован вручную, пришлите его в кривых.
- **Без чужих знаков.** Нет сходства с флагом Windows, логотипами Apple, Vue или Tailwind. Vue-зелёный — тоже не наш цвет.
- **Охранное поле и минимальный размер** знака и логотипа указаны на странице бренда.

- [ ] **Превью ссылки** 1200×630 (rowkit.dev) и **превью репозитория** 1280×640 (GitHub).
- [ ] **README:** hero 2560×1280 — ключевой визуал с разрезанным на темы экраном; три экрана 2400 шириной (таблица, набор компонентов, сайт документации) в единой брендовой рамке, каждый — в двух темах. Экраны внутри рамки — настоящие скриншоты, их я сниму из кода в нужном размере; от вас нужен макет рамки и композиции.
